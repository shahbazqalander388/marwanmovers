# Marwan Movers & Packers UAE 🚚🇦🇪

A modern, premium, professional, and fully responsive frontend website for **Marwan Movers & Packers**, a premier moving and packing company operating across all 7 Emirates in the United Arab Emirates.

---

## 🌟 Key Features

- **Bilingual English & Arabic (RTL)**:
  - Instant language switcher in navigation & footer.
  - Complete layout mirroring (`dir="rtl"`) with Arabic font **Cairo** and English font **Plus Jakarta Sans**.
  - Contact numbers and email remain correctly formatted.
- **Sticky Upper Header Navbar**:
  - `TopBar` and `Navbar` unified in a sticky header (`sticky top-0 z-40`) on both mobile and laptop views.
  - 24/7 service indicator, phone number (`+971 50 717 1355`), and 24/7 availability badges.
- **High-Converting Hero Section**:
  - Direct WhatsApp conversion and phone call triggers.
  - 4 trust badges (24/7 Availability, All UAE Coverage, Professional Team, Safe & Reliable Moving).
  - Quick interactive moving quote estimator.
- **12 Comprehensive Relocation Services**:
  - Home Moving, Office Moving, Villa Moving, Apartment Moving, Furniture Moving, Packing & Unpacking, Loading & Unloading, Local Moving, Long-Distance Moving, Commercial Relocation, Residential Relocation, and Furniture Dismantling & Assembly.
- **Dedicated Moving Types & UAE Coverage**:
  - Detailed sections for Apartments, Villas, Offices, Commercial Hubs, and Furniture.
  - Interactive grid covering **Dubai, Abu Dhabi, Sharjah, Ajman, Umm Al Quwain, Ras Al Khaimah, Fujairah, and Al Ain**.
- **Trust & Process**:
  - 8 verified "Why Choose Us" trust pillars (no fake stats/licenses).
  - 4-step "How It Works" moving process.
  - 8-question FAQ accordion in English and Arabic.
- **Interactive Moving Quote Form**:
  - Name, Phone, Pickup Location, Destination, Property Type, Moving Date, and Notes.
  - Interactive submission + **"Send via WhatsApp"** button that pre-populates the details to `+971 50 717 1355`.
- **Google Maps Integration**:
  - Embedded map for coordinates `25.3428211, 55.3979063` with a **"Get Directions"** button.
- **Floating Contact Buttons**:
  - Pulsing WhatsApp & Phone floating buttons for instant customer contact.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/ShahbazQalander388/marwan-movers.git

# Navigate to project directory
cd marwan-movers

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

### Production Build
```bash
npm run build
npm run preview
```
